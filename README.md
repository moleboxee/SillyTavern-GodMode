# 上帝之手 GodMode — SillyTavern 作弊引擎扩展

> AI 驱动的 SillyTavern 角色扮演作弊插件：一键剧情作弊、上帝法则、记忆篡改、时间回溯、命运推演、AI 世界书生成、同人小说导出……44+ 项功能，中文界面。

## 安装

在 SillyTavern 的 **扩展面板（🧩）→ Install extension** 中填入本仓库地址：

```
https://github.com/moleboxee/SillyTavern-GodMode
```

或手动克隆到 `data/default-user/extensions/godmode/`。

## 功能总览（44+）

### ⚡ 总控
- **上帝模式总开关**：一键关闭全部注入/维护/挂机，零 token 消耗
- **功能开关矩阵**：16 个 AI 功能独立启停
- **作弊强度分级**：🌤️轻推 / ⚖️中推 / 🔥强推，影响全部指令措辞

### 🎯 一键作弊（12 预设，右键可编辑文案）
我说了算 / 好感度MAX / 自动胜利 / 时间快进 / 暴富 / 满血复活 / 角色失控 / 剧情反转 / 读心术 / 天命预告 / 关系重置 / 详细模式

### 📜 上帝法则（永久开关）
禁止反抗锁 / 无敌模式 / 概率必中 / 天定结局 / 世界规则覆写 / 即死豁免 / 后宫力场 / 时间冻结

### 🧠 情报系统
- **记忆篡改**：改写角色"以为发生过的事"
- **挖黑历史**：AI 找角色把柄入库
- **意志画像**：AI 生成服从度预测卡（性格/态度/反抗倾向/最佳操控方式）
- **命运推演**：AI 模拟未来 2-3 条分支
- **读心术 / 天命预告**：揭示隐藏信息与伏笔

### ⏪ 时间线操作
- **单楼时间回溯**：回到任意楼层重玩（自动快照可撤销）
- **隐形改自己的楼**：修改你说过的话，AI 圆融矛盾
- **快照管理器**：可视化列表，任意快照直接回滚

### 🗂️ 世界书引擎
- **内置精选书一键收录**（全域神豪系统——系统流 RP 全套设定）
- 导入酒馆已安装 lorebook / JSON 文件
- 关键词扫描注入（上限可调）

### 🤖 自动化引擎
- **自动挂机**：定时推进剧情（防重入+失败熔断+静默快照）
- **状态栏自动同步 + 世界演化**：合并为一次调用省 50% token
- **风控自适应退避**：连续失败自动指数退避

### 🛠️ 工具
- **AI 世界书生成**：从剧情提炼实体→标准 lorebook
- **同人小说导出**：AI 整理成章回体小说
- **本地聊天导出**：Markdown/纯文本（零 AI 消耗）
- **AI 代笔**：你给意图 AI 写你的台词
- **注入预览复制**：调试看模型实际收到什么
- **作弊日志**：最近 100 条操作审计
- **全量备份**：整机配置一键导出/导入

### ⌨️ 快捷操作
- 15 条斜杠命令（`/god`、`/god-armor`、`/god-dice`…）
- 5 个全局快捷键（Ctrl+Shift+G/D/L/S/X）
- 楼层快捷按钮（➕扩写 / ➖缩写 / 🎬画面感 / 👤换视角）

## 使用

1. 右下角 😈 悬浮球打开面板（或 Ctrl+Shift+G）
2. 首次使用按引导接 API（任意 OpenAI 兼容端点 / WebLLM 本地模型均可）
3. 详细说明见 [使用指南](#)（随附文件）

## 安全与隐私

- 全部数据本地存储（`data/default-user/settings.json` 的 godmode 键）
- 导入文件有体积/条目护栏，动态 HTML 全部转义
- 不上传任何聊天内容
